## [Unreleased]

### Добавлено

- Исполняемый файл `exe/mini_agent`; новые опции `--base-url`, `--model`, `--version`.
- `Makefile` с целями разработки (`make help` — список): проверки, запуск агента, сборка и установка гема.
- Тесты RSpec (152 примера); HTTP стабится через webmock, живой LLM не требуется.
- Настройка таймаута команды через `COMMAND_TIMEOUT` (по умолчанию прежние 120 секунд).

### Изменено

- Монолитный скрипт `agent.rb` разобран на классы в `lib/mini_agent/`: `Agent`, `LLMClient`, `Conversation`, `ToolRegistry`, `Tools::Bash`, `CommandGuard`, `ProcessRunner`, `Prompt`, `UI`, `Config`, `Messages`, `Color`.
- Единый приоритет настроек: опции CLI → переменные окружения → значения по умолчанию. Раньше `base_url`, `api_key` и `model` читались только из окружения и игнорировали переданные опции.
- Раскраска вывода переведена с refinement на обычный модуль `Color`.

### Исправлено

- Флаг `--no-allow-unsafe` не мог перебить `ALLOW_UNSAFE=true`.
- Объект HTTP-запроса переиспользовался между повторными попытками обращения к LLM.
- В суммирующем запросе при достижении лимита ходов модели больше не предлагаются инструменты (`tool_choice: "none"`) — раньше возвращённые ею вызовы молча терялись.
- Вызов агента без предварительного открытия соединения падал с `NoMethodError`; соединение поднимается лениво.
- Ключи сообщений в истории приведены к единому виду (символы вместо смеси символов и строк).
- Пустая команда больше не запускает пустой shell, а возвращает понятную ошибку.
- Уточнён список опасных команд: убран неработавший шаблон, добавлены `wget | sh`, `doas`, `shutdown`/`reboot`, перезапись блочных устройств.
- Использование `Timeout::Error` без `require "timeout"` заменено на собственный `MiniAgent::TimeoutError`.
- По достижении лимита ходов просьба подвести итог отправляется ролью `user`, а не `system`: шаблоны чата Qwen и ряда других моделей принимают `system` только первым сообщением и отвечали HTTP 400.
- Тело ответа с ошибкой перекодируется в UTF-8: `Net::HTTP` отдаёт его как ASCII-8BIT, и склейка с русским текстом сообщения роняла клиент `Encoding::CompatibilityError` вместо показа самой ошибки сервера.
